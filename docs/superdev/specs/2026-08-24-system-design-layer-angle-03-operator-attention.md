# Angle 3 — The Operator's Attention Budget

**Purpose:** examine the whole organisation from its scarcest resource: the operator's time and energy.
**Formal anchors:** R3, R4, R17, R27 · D18, D19, D21, D29, D30 · §5.7.
**Series:** 3 of 3.

> **Status guide:** LOCKED · FLEXIBLE · DEFERRED · MISMATCH.

## The central question
Where is the operator genuinely irreplaceable, and how does the system spend those moments — and only those?

## The budget, enumerated

| Moment | Cost shape | Skippable? |
|---|---|---|
| item brainstorm (HIL) | minutes–hour, per item | deferrable via D30's ratification wait, never delegable |
| execution-shape agreement | one decision | no — it is THE flip (D29) |
| design session at a checkpoint | the big spend: rulings, visions, angle sweep | no — design is human-driven (D18); batching is the economy |
| checkride | per surface | operator's call |
| everything else | zero by design | rooms run, merge, mark, file — unattended |

LOCKED: there is no self-driven design; the system's throughput ceiling **is** this budget.

## Concrete consequences
- The front desk's DESIGN column is a **price display**: every ratification wait and design-dry pause shows its tick-time — what absence is costing, in withheld charters. FLEXIBLE (rendering).
- The orchestrator's checkpoint "feel" input is really an attention-economics judgment: fire when the residue collection justifies an operator sitting. LOCKED.
- Working ahead (visions, BLIND angles) happens only when the operator brings surplus energy to the architect room — the system never demands it. LOCKED.

## Visible collisions
- **Continuous development vs human-driven design:** development never waits (D3) yet design cannot advance alone (D18) — reconciled by markers + scoped charter-withholding (D21): the present borrows against the future, visibly, in greppable debt.
- **More rooms = more parallelism, but every room's brainstorm bills the same budget** — the real cap on fan-out is not coordination, it is operator brainstorm-minutes per week. DEFERRED: the R22 deep-dive should say how much brainstorm a broad-arc item actually needs.

## Reconciled outcome
The organisation is shaped so that the operator's attention buys only the three things nothing else can produce — detail rulings, design rulings, and trust ("checkride") — and every other minute of system time is spent without them.
